# Validated Results

### Results and Validation

The project includes Excel-based calculations, processed data, and illustrative visualizations for traffic signal design, design traffic estimation, axle-load analysis, and rigid pavement fatigue assessment.

The calculations are documented for academic review. Certain formulas, assumptions, and intermediate results require further verification, as detailed in the Technical QA Register (`report/technical-qa-register.csv`). Final design values should be confirmed against the applicable engineering standards before practical use.
